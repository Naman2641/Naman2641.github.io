Signspeak

Personal project

Reads the ASL alphabet, numbers and common words off a live camera feed and turns them into text.

Each finger is judged by how far it extends and how much it curves. A sign only counts after it holds steady across several frames, so a half-formed one never gets typed. It can speak the result, keeps a gesture library and a detection history. Everything runs in the browser, so no video leaves the device.

ETHiCare VitalSense

Codethon project

Picks out stress and cardiac abnormalities from wearable physiological data, built around the WESAD and ECG datasets.

Two services. A Node.js one handles authentication, experiments and reports. A Python FastAPI microservice does the preprocessing, feature extraction and model inference. The front end animates the signals, and the model's results are compared against published literature.

ThoughtFirewall

Hackathon project

A real-time dashboard that scores manipulation risk from 0 to 100 in ads, clickbait and misinformation, and explains the tactics in plain language.

Analysis events stream over WebSockets while a six-agent reasoning pipeline works through the text. A reframe mode shows other ways to read the same thing, and source-trust analytics keep track of who is saying it.

SEAMS motion alarm

College project

An Arduino Uno system that watches for movement and raises an alarm when there hasn't been any.

An ultrasonic sensor reads distance, an I2C LCD shows it with the current status, and LEDs escalate through alert levels. When the no-motion timeout runs out, a servo and buzzer go off. Separate Demo and Real modes use different timing thresholds, so it can be shown on a desk without waiting around.
